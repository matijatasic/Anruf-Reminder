# Sicherheit

## Lücke melden

Bitte Sicherheitsprobleme **nicht** als öffentliches Issue melden. Nutze stattdessen die private Meldung von GitHub:
**Security → Report a vulnerability** in diesem Repository.

Hilfreich sind: betroffene Version, Handy-Modell und Android-Version, Schritte zum Nachstellen.

## Was als Sicherheitsproblem gilt

- APKs unter Releases, deren Signatur nicht zum Fingerabdruck im README passt
- Wege, über die andere Apps Erinnerungen auslesen oder Anrufe auslösen können
- Alles, was Daten das Gerät verlassen lässt (die App hat keine Internet-Berechtigung)

## Unterstützte Versionen

Nur die jeweils neueste Version unter Releases erhält Korrekturen.
